Como publicar

1. Extraia o arquivo ZIP.
2. Envie todos os arquivos e pastas para a raiz de um repositório no GitHub.
3. Na Vercel, escolha Add New Project.
4. Importe o repositório.
5. Em Framework Preset, escolha Other.
6. Não preencha Build Command.
7. Mantenha Output Directory vazio.
8. Clique em Deploy.

Como configurar o WhatsApp

Abra o arquivo script.js.
Localize a linha:

const WHATSAPP_NUMBER = "";

Insira o número com código do país e DDD, usando apenas números.
Exemplo:

const WHATSAPP_NUMBER = "5577999999999";

Depois salve o arquivo e envie a alteração ao GitHub.

Não renomeie ou mova as pastas imagens e videos, pois o index.html utiliza esses caminhos.
